# 週次・会社重要データ分析レポート

Google Drive上の会社重要データを毎週自動で読み込み、**前回対比**を分析して
**Slack DM**へ報告する仕組み。

## 構成
- `config.json` … 対象6ファイル（fileId・役割）、Slack送信先、スケジュール設定
- `RUNBOOK.md` … 週次実行セッションが従う手順書（読む→前回対比→Slack投稿→スナップショット保存）
- `snapshots/latest.json` … 直近の主要指標（次回の前回対比の基準）
- `snapshots/YYYY-MM-DD.json` … 各週の指標履歴

## 対象データ（6ファイル）
1. 16期集計 — 全社の売上・契約・反響 進捗ダッシュボード
2. 売買部データ_セールスファネル — 売買部門の反響→成約ファネル
3. クラフト顧客管理シート16期 — CR(リフォーム)の月間KPI
4. 会員登録顧客まとめ(xlsx) — 会員登録顧客のまとめ
5. 会員登録反響リスト — 会員登録フォーム反響の明細
6. Meta物件広告 — 物件広告(LP)反響の明細

## 動作
週次Routine（Claude Code Remoteのトリガー）が毎週決まった時刻に新しいセッションを起動し、
`RUNBOOK.md` の手順を実行する。前回対比のため、毎回スナップショットをこのリポジトリに保存する。

## スケジュール変更
`config.json` のメモ参照。曜日・時刻の変更はRoutineのcronを更新する。
