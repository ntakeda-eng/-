# ウィローズビルド 期別×種別 販売分析

BU_CFの「入力シート」を1物件1行で抜き出し、売却決済日で期に振り分けて集計する。
集計はすべてExcel数式（COUNTIFS/SUMIFS/AVERAGEIFS）なので、物件データや設定を直せば全表が連動する。

## 実行手順

1. アップロードされたBU_CFのパスを確認する（シート名「入力シート」があるもの）
2. スクリプトを実行（基準日は通常「今日」。実績／予定の境目になる）

   ```bash
   python .claude/skills/willows-build-sales-by-period/scripts/build_report.py <BU_CF.xlsx> output/ビルド_期別種別販売分析.xlsx YYYY-MM-DD
   ```

3. xlsxスキルの `scripts/recalc.py` で再計算し、`status: success`・`total_errors: 0` を確認する
   - LibreOfficeが「source file could not be loaded」やタイムアウトになる場合は Calc が入っていない。`apt-get install -y libreoffice-calc` で入れてから再実行
4. 検算：②の合計行（棟数・売上高）を Python で入力シートから直接集計した値と突き合わせる
5. ユーザーにファイルを渡し、下記「必ず伝えること」を添える

## 出力ブックの構成

| シート | 内容 |
|---|---|
| 物件データ | 入力シートからの抽出（青字＝転記値、黒字＝数式）。期・状態（実績/予定/未売却）・粗利・粗利率・保有日数・価格帯・データ注記。売却決済日順、未売却は末尾 |
| ①期別×種別 | 期×物件種別の棟数マトリクスと構成比 |
| ②種別別KPI | 種別×期で 棟数／売上高／粗利／粗利率／平均保有日数／原価未入力棟数 |
| ③成約価格分布 | 期ごとの棟数・平均成約価格・最低・最高・売上合計、5,000万円きざみの価格帯別棟数と構成比、棒グラフ |
| 設定 | 基準日、集計対象（全て／実績のみ）、価格帯の刻み、期の開始・終了日、前提 |

## 定義（ここを間違えない）

- **期 = 売却決済日で判定**。ビルド期数 ＝ グループ期数 − 2
  - 9期 2021.7–2022.6 ／ 10期 2022.7–2023.6 ／ 11期 2023.7–2024.6
  - **12期 2024.7–2024.9（決算期変更の3ヶ月変則）** ← 他期と横並びで比較しない
  - 13期 2024.10–2025.9 ／ 14期 2025.10–2026.9 ／ 15期 2026.10–2027.9
- **売上高・成約価格** ＝ 入力シートH列「販売価格」
- **粗利（会計）** ＝ 販売価格 − 仕入原価（I〜M列）− 商品化原価（P,R,T,V,X,Z,AB,AD,AF,AH,AJ列）
  - 販売諸費用（AP列）・支払利息は含めない。手残りベースの議論は `willows-build-inventory-plcf` スキルに従う
  - **仕入原価が未入力の物件は粗利・粗利率から除外**（売上高・棟数には含める）。除外棟数は②の最下段に出る
- **保有日数** ＝ 売却決済日 − 仕入決済日
- **状態**：売却決済日 ≤ 基準日 → 実績、> 基準日 → 予定（入力シートは計画値も混在している）

## 入力シートのクセ

- 日付がExcelシリアル値（例 45230）で入っている行がある → スクリプトで日付に変換済み
- 仕入契約日に `520318` のような誤入力がある（仕入契約日は集計に使わない）
- 販売価格が空欄なのに売却決済日がある行、物件種別が空欄の行、AP列に文字（"r"）が入った行がある → 物件データの「データ注記」列に出る
- 古い期（10期）はほぼ全件、仕入原価が入っていない → 10期の粗利は参考値にもならない
- 種別の表記ゆれ（「立ち退き後転売土地」と「たちのき後転売MS」など）はそのまま別種別として集計する。統合するなら物件データのB列を直せば連動する

## 必ず伝えること

1. **粗利の網羅率**：期ごとに「原価未入力で除外した棟数」を示し、粗利率がどの母数で出ているか明言する
2. **実績と予定の混在**：基準日以降の決済は計画値。「実績のみ」に切り替えた数字も併記する
3. **12期は3ヶ月**なので、売上高・棟数を他期と単純比較しない
4. 平均成約価格は高額物件1件で大きく動く（例：JT・一棟・大型土地）。価格分布とあわせて読むよう促す
5. 数字から見える論点は Yesマンにならず指摘する（例：種別構成の変化、保有日数の長期化、粗利率がマイナスの期・種別）

## xlsx作成ルール

- フォント Meiryo。入力セルは黄色（FFF2CC）＋青字、数式は黒
- `XLOOKUP`/`FILTER`/`SORT`/`UNIQUE` は使わない。`MINIFS`/`MAXIFS` は `_xlfn.` を付ける
- recalc で errors_found が出たまま納品しない
