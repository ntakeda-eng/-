# ウィローズクラブ 週次分析レポート

「⭐紹介・リピートリスト」スプレッドシート（16期入力用タブ）を毎週自動で解析し、
**① 会員内の行動の実数 / ② 誰がどの位獲得したか / ③ 今期の着地見込み** を
Slack に週1回レポートする仕組み。

- 対象スプレッドシート: `1VyWfjLR4v2bMu8ccqPj01lN67e5Hn3KLj-NqG3J8XM4`（⭐紹介・リピートリスト）
- 対象タブ: `16期入力用`
- 配信: 毎週金曜 17:00（JST）／ Slack **#ウィローズクラブ社内紹介分析**（`C0BH8036LAY`）
- 会計年度: **16期 = 2025/10/1 〜 2026/9/30**

各種パラメータ（配信先チャンネル・対象シート・会計年度）は [`config.json`](config.json) に集約。
配信先を変えるときは `config.json` の `slack_channel_id` を書き換え、週次トリガーを作り直す。

---

## レポートで分かること

| # | 項目 | 内容 |
|---|------|------|
| ① | 会員内の行動の実数 | 紹介/リピート総登録数、成約件数・成約率、種別内訳（リピート/紹介/社員が源泉/未成約者から紹介）、事業内訳 |
| ② | 誰がどの位獲得したか | 社員別の「社内紹介ポイント」ランキング（紹介/リピート/他部門紹介の件数付き） |
| ③ | 今期の着地見込み | 紹介取得日ベースの月次ペースから算出した年間着地予測（月次推移付き） |
| ④ | 会員(お客様)側 | 紹介・リピートが多いクラブ会員 上位 |

各項目に **前週比** が付く（前週スナップショットと比較）。

## ポイント集計ロジック（スプレッドシートの定義に準拠）

- **社内紹介ポイント（＝②の「獲得」）**: `社員POINT` 列を「社内紹介を出した人（＝ポイント取得者）」ごとに合計。
  ルール上「紹介 or 成約のどちらかでカウント（二重加算しない）」。事業別の付与pt例:
  - 賃貸(借/貸) 紹介0.1〜1 / リフォーム見積 紹介0.1・成約1 / 人事・法人提携 成約2 など
- **クラブポイント（お客様向け）**: `紹介・相談P` と `成約P` の発行合計。
  - 賃貸 紹介500・成約3,000 / 売買・投資 紹介1,000・成約10,000 / リフォーム成約は請負金額に応じ最大10,000 等
- 集計値は既存「ランキング」タブ（数式）と一致することを検証済み。

> 期が変わったら `analyze.py` の `FY_LABEL / FY_START / FY_END / SHEET` を更新する。

## 使い方（手動実行）

```bash
# 1) スプレッドシートを xlsx でダウンロード（Google Drive）
#    → /tmp/willows.xlsx として保存
# 2) 解析＆レポート生成（前週比つき・当週スナップショット保存）
python3 analyze.py /tmp/willows.xlsx \
    --prev snapshots/前週分.json \
    --save snapshots/当週分.json
```

- `--today YYYY-MM-DD` : 基準日を固定（テスト用）
- `--json` : レポートでなく生の集計JSONを出力
- `snapshots/` : 週次スナップショット（前週比の元データ）。毎週コミットして履歴を残す。

依存: `python3`, `openpyxl`（`pip install openpyxl`）

## 週次自動化の仕組み

毎週金曜 17:00（JST）にスケジュール実行（Claude Code のスケジュールトリガー）で、
新規セッションが以下を自動実行する:

1. 対象ブランチ `claude/willows-club-analytics-ehe2ae` を fetch/checkout
2. Google Drive から対象スプレッドシートを xlsx でエクスポート
3. `analyze.py` を実行（直近の `snapshots/*.json` を `--prev` に指定）
4. 生成レポートを Slack チャンネル（`config.json` の `slack_channel_id`）に投稿
5. 当週スナップショットを `snapshots/` にコミット（翌週の前週比用）

配信先やタイミングを変えたい場合は `config.json` を更新のうえスケジュールトリガーを作り直す。
